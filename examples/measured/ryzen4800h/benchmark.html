Compare each batch's per-request latency with its samples/second. Larger batches can increase throughput while increasing request latency and RSS. Limitations and methodology

  • Model loading, compilation, input generation, and serialization are excluded from steady-state timing. A first inference is timed separately before the configured warmup. Timed inference includes synchronous output normalization into host arrays.
  • P50/P95/P99 use NumPy linear percentiles; standard deviation is the population statistic. Throughput is processed samples divided by the sum of timed inference durations.
  • RSS is total process resident memory in decimal MB, including libraries and allocators. It is not model-exclusive memory. RSS is sampled every 20 ms during warmup/measurement; observed peaks can miss shorter allocations. Earlier batches can retain allocations.
  • Backend graph optimizations and thread schedulers differ. A matching requested thread count does not guarantee identical resource use. Check effective backend settings. No universal backend speed claim follows from this report.
  • Thermal state, CPU boost, power policy, background load, process affinity, and run order affect measurements. Repeat runs in fresh processes on an otherwise idle machine.
  • Microbenchmarks are not end-to-end application performance. AMD OpenVINO compatibility is established only when actual CPU compilation, inference, and numerical checks succeed.
